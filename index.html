Bloatware

Scan for known background processes (HP, McAfee, Brave, Edge, IObit, and more) and kill them to free up memory and CPU. You can also stop and disable their services in the same step.

System Health
SFC, DISM, chkdsk, repair commands

System Health Check (read-only)

These commands only report on Windows' health. They do not change anything on disk and are safe to run anytime. Output streams into the Activity Log on the right as the command progresses.

SFC /scannow
Verifies protected Windows system files and reports any corruption. Takes 5 to 20 minutes. Repair is delegated to DISM /RestoreHealth below if SFC finds something it can't fix on its own.
DISM /CheckHealth
Quick read of the component store's previously stored health flags. Returns in seconds. Use this as a first sanity check before the longer scans.
DISM /ScanHealth
Full scan of the component store for corruption. Takes a few minutes. Tells you whether DISM /RestoreHealth needs to do anything.
DISM /AnalyzeComponentStore
Reports WinSxS size and whether Windows recommends running a component cleanup to reclaim space. Read-only diagnostic.

Repair & Cleanup (writes changes)

These actually modify the system. Each one prompts for confirmation. DISM /RestoreHealth needs internet to download replacement files. Chkdsk on the system drive cannot run live, so it schedules a check for your next reboot.

DISM /RestoreHealth Needs internet
Repairs corruption in the Windows component store by downloading clean copies from Windows Update. Takes 10 to 30 minutes. Run this after SFC reports issues it could not fix on its own.
DISM /StartComponentCleanup Irreversible
Removes superseded WinSxS components to reclaim disk space. After this completes you lose the ability to uninstall the specific Windows updates that were cleaned up. Other updates are unaffected.
chkdsk /f /r /x (system drive) Schedules reboot scan
Checks the system drive for file system errors and bad sectors. Because the drive cannot be locked while Windows is running, this only SCHEDULES the scan for your next reboot. The PC will be unusable during that scan (typically 30 minutes to 2+ hours).
Reset Microsoft Store cache (wsreset)
Clears the Microsoft Store's local cache. Use when Store apps won't install, update, or open. Heads up: a Microsoft Store window will pop open automatically when the reset finishes. That's expected.
System Tools
Quick tweaks, Windows utilities

Quick Tweaks & Windows Tools

Persistent system settings that trade visual polish or features for speed. Each one writes registry or boot config and takes effect on next sign-in or reboot. All are reversible from Windows Settings or by re-running the opposite command.

Adjust for Best Performance (Visual Effects)
Sets HKCU VisualFXSetting = 2 and disables window animations. Same as System Properties → Performance → "Adjust for best performance". Sign out and back in for full effect on shell animations.
Trim Boot Settings Effective next reboot
Runs bcdedit to set the boot menu timeout to 3 seconds and enable quiet boot (hides the Windows boot logo / spinner). Saves a few seconds on boot. Does NOT touch the "Number of processors" option in msconfig, because that setting does not improve boot speed on modern Windows.
Switch to High Performance Power Plan
Activates the well-known High Performance power scheme via powercfg. Trades battery life for sustained CPU/GPU performance and faster wake. Switch back from Windows Settings → Power & battery, or by re-running the Balanced plan from Control Panel.
Open Disk Cleanup
Launches the classic cleanmgr.exe utility. Useful for clearing Windows Update cache, old Windows installations, system error reports, and the Recycle Bin in one place. Complements the temp folder clears above.
Open Windows Update
Opens Settings → Windows Update. From there, click "Advanced options" → "Optional updates" to install drivers and feature updates that Windows holds back from the main rollout.
Optimize System Drive
Runs Optimize-Volume on your system drive. Windows automatically picks TRIM for SSDs and defragmentation for HDDs based on the volume's media type. Output streams into the Activity Log. Modern Windows runs this on a schedule, so a manual pass is usually only worth it if you just bulk-deleted a lot of files.

System Maintenance
Restore points, hibernation, background apps

System Maintenance

Create a manual System Restore Point before applying any major changes, toggle hibernation to reclaim several GB of disk space (hiberfil.sys), and mass-disable background AppX apps to save RAM. Restore points let you roll back if anything goes wrong.

Create System Restore Point
Creates a manual checkpoint you can roll back to via Settings -> System -> About -> System Protection. System Protection is enabled on C: if not already on.
Delete All System Restore Points
Runs vssadmin delete shadows /for=C: /all on the system drive. Frees the disk space reserved by every existing restore point. You will no longer be able to roll the system back to a previous state until you create a new one.

Connection Status

Pings your router, then 8.8.8.8 (raw internet) and google.com (DNS) to pinpoint where the connection breaks. Click Run Diagnostics to start.

Click Run Diagnostics to test your connection.

DNS & IP Fixes

Safe, reversible network tweaks. Pick one if a specific site won't load, browsing feels slow, or you just changed network settings and need Windows to pick them up.

Switch to Google + Cloudflare DNS
Sets this adapter's DNS to 8.8.8.8 and 1.1.1.1, then flushes the cache. Often fixes "page not found" errors and slow lookups caused by your ISP's default DNS.
Reset DNS to Automatic
Reverts to whatever DNS your router / DHCP hands out. Use this to undo the Google+Cloudflare switch above.
Flush DNS Cache
Clears the local cache of domain-to-IP lookups. Use after changing DNS records, switching VPN profiles, or when a site loads from a stale entry.
Renew IP Address
Releases your current IP and asks your router for a new lease. Use when you got a bad IP (limited connectivity, IP conflict) or you joined a new network and want a fresh address. Briefly disconnects.

Heavy Resets

Use these only after the safer fixes above didn't help. Both require a Windows restart to take effect and can undo settings created by VPN, proxy, or antivirus software.

Reset Winsock Restart required
Rebuilds the Windows socket catalog from scratch. Removes broken or malicious LSPs (Layered Service Providers) that VPN or filtering software may have left behind. Use when nothing reaches the internet despite the connection looking fine.
Reset IP Stack Last resort
Rewrites the entire TCP/IP stack back to factory defaults at the registry level. Use only after Winsock reset didn't help. Will wipe any custom routing or IP configuration you have set up.
Ready
Read-only: Disk Reaper does not download or install driver updates. This panel only lists your installed drivers and cross-checks their versions against Microsoft's update catalog so you can see what's behind. To actually apply an update, use Windows Update (Settings → Windows Update) or download from the device manufacturer's website.

Catalog coverage: "Check for Updates" only sees drivers published through the update services registered on this PC. By default that's Windows Update alone, which has a thin driver catalog. Click Enable Microsoft Update to add the broader Microsoft Update catalog (same as Windows Settings → Windows Update → "Receive updates for other Microsoft products"). Vendor-direct releases (NVIDIA GeForce, AMD Adrenalin, Intel direct downloads, laptop OEM tools) often arrive on vendor sites first and may never hit Microsoft's catalog at all. "No update found" means the Windows Update Agent has nothing newer to offer your specific device today. Microsoft uses staged rollouts and per-device targeting, so an update can exist on the public Microsoft Update Catalog at catalog.update.microsoft.com and still be filtered out by the agent for your hardware ID or Windows build. To check the raw catalog yourself, search catalog.update.microsoft.com directly.
